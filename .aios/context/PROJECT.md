# FocusFlow Project Context

FocusFlow is a productivity application.

## Main stack

Frontend:

- React
- TypeScript
- Vite
- React Hook Form
- Zod
- Tailwind CSS
- clsx version 2.1.1
- React Router DOM
- Redux Toolkit version 2.12.0
- Axios version 1.16.1
- Vitest version 4.1.10
- i18next version 26.2.0

Backend:

- Java 21
- Spring Boot 4.0.6
- Maven
- Spring MVC
- Spring Security
- Spring Data JPA
- Hibernate
- Jakarta Validation
- PostgreSQL Driver
- JJWT
- Spring Mail
- Lombok
- JaCoCo

Database:

- PostgreSQL

## Main domains

- Authentication
- User
- Tasks
- Hobbies
- Scheduling
